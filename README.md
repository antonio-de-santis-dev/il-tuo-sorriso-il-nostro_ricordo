## Mockup

Prototipi statici (HTML/CSS/JS, nessuna dipendenza), da aprire nel browser:

- `design/mockup/index.html` — Home completa con intro animata (aggiungere `?intro` all'URL per rivederla)
- `design/mockup/album.html` — pagina album con selezione multipla e lightbox

Per servirli in locale: `npx serve design` e poi aprire `/mockup/`.
Screenshot desktop e mobile in `design/screenshots/`.
